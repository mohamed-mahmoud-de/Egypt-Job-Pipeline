I want to understand a concept deeply before writing any code.

Follow this sequence exactly:

1. ELI5 — explain it in one sentence like I am five
2. REAL EXPLANATION — the actual version with a relatable analogy.
   Compare to things I already know: Postgres, REST APIs, Discord bots,
   Python scripts, cron jobs.
3. IN OUR PROJECT — how this concept applies specifically to the
   Egypt Jobs Pipeline
4. TEST ME — ask me to explain it back in my own words
5. CORRECT — if I get it wrong, clarify without judgment

Do NOT show any code during this explanation.
Concepts first, code always comes later.
